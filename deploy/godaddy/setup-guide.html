Section 2

Check your GoDaddy account first

Do this before anything else. It takes two minutes.

GoDaddy sells several products. Only one of them can hold this website. Check which one you have before you upload anything.

  1. Sign in to GoDaddy.
  2. Open My Products. Look at the headings on the page.

Section 3

Upload your website

  1. Open cPanel. My Products → Web Hosting → Manage → cPanel Admin
  2. Open File Manager. Then double-click the folder called public_html. This folder is your website. Whatever is inside it is what people see.
  3. Delete GoDaddy's starter page. Look for index.html, default.html, or a folder called "coming soon". Delete them. This step matters. If you leave them, your website will not appear.
  4. Click Upload. Choose manussa-site.zip. Wait until it reaches 100%.
  5. Unzip it. Go back to File Manager. Right-click the zip file. Choose Extract. Then delete the zip file. You do not need it any more.
  6. Open your website address in a browser. Your website should be there.
If the upload stops before it finishes

The file is big. Your computer calls it 67 MB. cPanel calls the same file 64 MB. Both are correct. They count in different ways.

Web browsers sometimes cannot finish a file this big. If yours stops, use FTP instead. FTP takes longer to set up, but it does not give up.

  1. In cPanel, open FTP Accounts. Write down the server name, username and port.
  2. Download FileZilla. It is free.
  3. Connect with those details. Then drag the files into public_html.

Section 4

Check the hidden file

File Manager hides .htaccess until you ask it not to.

  1. Click Settings in the top right of File Manager.
  2. Tick "Show Hidden Files (dotfiles)". Then click Save.
  3. Look inside public_html again. You should now see .htaccess next to index.html.
You are finished when public_html holds these nine things
  • index.html
  • 404.html
  • robots.txt
  • sitemap.xml
  • .htaccess hidden
  • _assets folder
  • fonts folder
  • favicon.png
  • apple-touch-icon.png

Section 5

The padlock

The padlock in the address bar means the website is secure. GoDaddy gives you this for free.

It is not ready straight away. It can take a few hours after your web address points at the hosting.

How to test if it is ready

Type https:// in front of your web address. If the page loads, it is ready. If you see a warning, wait and try again later.

When it is ready

You can send every visitor to the secure version automatically.

  1. Right-click .htaccess in File Manager. Choose Edit.
  2. Find these five lines near the top.
    # <IfModule mod_rewrite.c>
    #  RewriteEngine On
    #  RewriteCond %{HTTPS} !=on
    #  RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
    # </IfModule>
  3. Delete the # at the start of each of the five lines. Leave everything else exactly as it is.
  4. Click Save.
Important

Only do this after the padlock works.

If you do it before, your website will stop working for everyone. That includes you.

Section 6

If something looks wrong

What you seeWhat to do
Plain text. No photos. No colours. The _assets or fonts folder did not unzip. Unzip the file again.
A GoDaddy "coming soon" page The starter page is still there. Delete it from public_html. Then refresh.
The old page, even after uploading Your browser is showing a saved copy. Open a private window. Or wait ten minutes.
The website is slow. Photos take a long time. .htaccess is missing. Go back to section 4.
A list of file names instead of the website index.html is one folder too deep. Move all the files up into public_html.
The website stopped working after you edited .htaccess The padlock was not ready. Put the # back at the start of those five lines.

Section 8

Changing the website later

This website does not store anything. There is no database. There are no accounts and no orders.

That makes updates simple. New files replace old files. Nothing is lost.

When you get a new version

  1. Upload the new zip to public_html.
  2. Unzip it over the top of the old files.
  3. Keep .htaccess. Do not delete it.

If your web address changes

Four files have the web address written inside them. Google and social media read them. Ask for a new zip instead of editing the files by hand. It takes less than a minute to make.

If anything on your screen does not match this guide, send a screenshot. It usually means GoDaddy has moved a button. It is quicker to check than to guess.
